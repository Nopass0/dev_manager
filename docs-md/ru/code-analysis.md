# Анализ кода

> Раздел: [Документация](./README.md)

Dev Manager разбирает исходный код через **tree-sitter** и предоставляет:
- извлечение символов (функций/классов/структур) с сигнатурами и doc-комментариями;
- линтеры: DRY, KISS, дубликаты, неиспользуемый код;
- основу для `dm commit auto`.

## Запуск

```sh
dm lint            # все сервисы
dm lint api        # только сервис api
```

Включённые проверки берутся из секции `linter:` в `dm.yaml`:
```yaml
linter:
  dr: true
  kiss: true
  unused_code: true
  duplicates: true
  auto_fix: false
```

## Категории замечаний

### `duplicate` — дублирующиеся определения
Символ с одинаковым `(имя, категория)` определён в **разных файлах**. Часто
бывает при копипасте или случайном конфликте имён в монорепо.

### `dry` — нарушение DRY
Функция с одинаковым именем встречается в нескольких файлах — возможный
копипаст-дубликат.

### `kiss` — нарушение KISS
- Функция с числом параметров > 6 — возможно, стоит сгруппировать в структуру.
- Функция длиннее 80 строк — рассмотрите разбиение.

Пороги консервативны и настраиваются в исходниках (`crates/dm-analysis/src/lints/kiss.rs`).

### `unused` — неиспользуемый код
Имя символа встречается в проекте только в собственном определении (менее
2 вхождений во всех файлах). Эвристика без графа вызовов — простая, но
эффективная; возможны ложные срабатывания для динамической диспетчеризации.

## Поддерживаемые языки

В этой версии: **Rust, JavaScript, TypeScript, Go**.

Добавление языка — реализация трейта `LanguageParser` (в
`crates/dm-analysis/src/languages/`) и регистрация в `parser_for_extension`.
Любая tree-sitter-грамматика подключается аналогично.

## Doc-комментарии

Распознаются:
- Rust: `///`, `//!`, `/** */`;
- JS/TS: JSDoc `/** ... */`, `//`;
- Go: `//` над определением.

Первый абзац doc-комментария используется в `commit auto` и отчётах.

## `dm commit auto`

Использует тот же tree-sitter-движок: для каждого изменённого файла `dm` берёт
версию из `git HEAD` и версию с диска, сравнивает символы и формирует сообщение
с типом изменения (`добавлена`/`изменена`/`удалена`).
