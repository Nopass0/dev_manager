🛠️ Dev Manager

Unified microservices development manager: orchestrate, automate git, analyze code, scaffold projects, and deploy — all from one console.

Download View on GitHub
# Install (one line): curl -fsSL https://raw.githubusercontent.com/Nopass0/dev_manager/main/scripts/install.sh | sh # Create a project from template: dm init --template=bun-elysia --name=myapi dm setup && dm start

📦 Install

Windows (PowerShell)

iwr -useb https://raw.githubusercontent.com/Nopass0/dev_manager/main/scripts/install.ps1 | iex

Linux / macOS

curl -fsSL https://raw.githubusercontent.com/Nopass0/dev_manager/main/scripts/install.sh | sh

From source

git clone https://github.com/Nopass0/dev_manager
cd dev_manager && cargo build --release

Requires: Rust nightly 1.93, C compiler (MSVC/gcc), git in PATH.

✨ Features

🚀

Process Orchestration

Launch microservices with start queue, delays, health-gated dependencies, and guaranteed process-tree kill. Auto-recovery after 5 crashes.

🔄

Hot Reload

File watcher tracks changes and restarts only the affected service. Smart restart: ignores lock/data files.

🧬

Flexible Config

Inheritance (extends), environments (dm.<env>.yaml), interpolation, defaults, profiles, tags, only_on filter.

🏗️

Project Templates

12+ templates: Bun/Elysia, Go, Rust/axum, Next.js, SvelteKit, Python/FastAPI, C#. One command: dm init --template=...

🔧

Git Automation

Multi-repo commit/push/update, commit auto (tree-sitter), conventional commits, auto-CHANGELOG, semver bump.

🔍

Code Analysis

DRY/KISS/unused/duplicates via tree-sitter. grep/replace/refs, secrets scan, dependency graph, Mermaid diagrams.

📋

Kanban Board

dm board launches a local kanban board on port 11001 with drag-and-drop tasks in a hashed file.

🔔

Notifications

Webhook (Slack/Telegram/Discord) + desktop toast (auto-dismiss). Alerts on crashes, test failures, limit breaches.

🏗️

Build Pipeline

Multi-stage build: assemble artifacts from different languages (DLL + exe) into one clean dist/ folder.

📁 Templates

dm init --list-templates          # list all
dm init --template=bun-elysia     # create Bun backend
